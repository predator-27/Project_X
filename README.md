# Project X 🚀

An Android application built with Modern Android Development practices, Jetpack Compose, Material 3, and Firebase.

## Features 🌟
- **Jetpack Compose UI & Material 3**: Modern, responsive, and adaptive UI design.
- **Teacher & Student Management**: Interactive scheduling and appointment requests.
- **Gemini AI Integration**: Multi-modal image and text prompt processing with BakingScreen.
- **In-App Auto-Update System**: In-app updates with GitHub Release synchronization.
